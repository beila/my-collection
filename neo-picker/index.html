Install Neo Picker

Neo Picker is a browser bookmark that runs inside the Instapaper page. The Instapaper item named Neo Picker only opens this installer; it does not run the picker.

  1. Create a bookmark in your browser, not inside Instapaper.
  2. Edit that bookmark and name it Neo Picker.
  3. Copy the code below and replace the bookmark URL with it.
  4. Open Instapaper and invoke the Neo Picker browser bookmark.
Neo Picker

On mobile, keep Instapaper in the current tab. If the bookmark list does nothing, type Neo Picker in the address bar and select the bookmark suggestion. Desktop browsers can drag the link to the bookmarks bar.
