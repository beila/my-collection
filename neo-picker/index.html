Install Neo Picker

Neo Picker runs inside the Instapaper page. The Firefox Android extension adds a one-tap launcher. The browser bookmark remains a fallback for browsers that execute JavaScript bookmark URLs.

Firefox Android extension

Install the Mozilla-signed package once. Firefox checks for signed Neo Picker updates automatically after installation.

Install permanent Firefox extension

Checking the signed release…

  1. Download the signed XPI in Firefox on the new device.
  2. Approve the Firefox add-on installation prompt.
  3. Open Instapaper and confirm that the Neo button appears.

The development ZIP is for temporary USB debugging only. It does not survive a Firefox restart or update.

Bookmarklet fallback

The Instapaper item named Neo Picker only opens this installer. It does not run the picker.

  1. Create a bookmark in your browser, not inside Instapaper.
  2. Edit that bookmark and name it Neo Picker.
  3. Copy the code below and replace the bookmark URL with it.
  4. Open Instapaper and invoke the Neo Picker browser bookmark.
Neo Picker

On mobile, keep Instapaper in the current tab. If the bookmark list does nothing, type Neo Picker in the address bar and select the bookmark suggestion. Vivaldi 8.2 Android does not execute JavaScript bookmark URLs from either path. Desktop browsers can drag the link to the bookmarks bar.
