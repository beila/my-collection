Install Neo Picker

Neo Picker runs inside the Instapaper page. It reads the current Neo RSS when it opens and whenever you choose another bookmark.

  1. Bookmark this page in the browser that will run Neo Picker.
  2. Edit that bookmark and name it Neo Picker.
  3. Copy the code below and replace the bookmark URL with it.
  4. Open Instapaper, then invoke the Neo Picker bookmark.
Neo Picker

Desktop browsers can drag the Neo Picker link to the bookmarks bar. Mobile browsers usually require editing an existing bookmark.
