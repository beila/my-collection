바이브 코딩에도 [ 감리 ]가 필요하다.

내 AI를 감시할 또 다른 AI를 소개한다.

-----

바이브 코딩을 하다보면,

겉보기에 잘 돌아가는 것 같은 느낌에 속기가 쉽다. 내 의도대로 화면이 잘 나오긴 하지만, 내부적인 논리에 오류가 생길 수도 있고, 보안에 취약할 수도 있는데, 개발자가 아닌 입장에서 그걸 찾아내는 게 쉽지 않다.

ㅤ

이때 활용할 수 있는 게 [ Freebuff ] 다.

한마디로 이야기하면 코드계의 '감리' 같은 역할인데, 이미 작성한 코드를 아키텍처, 보안, 엣지케이스 등 다각도에서 검증하고 레포트를 만들어 준다. 코딩과 감리가 같은 계열의 모델이면 신뢰도가 떨어지는데, Freebuff 는 'Solar Pro'라는 별도의 AI 모델을 사용하기에 객관성이 높다.

ㅤ

그렇다면 Freebuff 가 어떻게 감리를 하카.

핵심 원리는 TCDD라고 하는 엄격한 순환루프다. [ 테스트 ➔ 코드변경 ➔ AI리뷰 ➔ 수정 ]을 모두 통과해야 작업을 완료한다. 건물도 안전을 보장하기 위해서 내부적인 테스트와 외부 감리를 반복하는데, 소프트웨어 역시 이렇게 감리해야 구조가 튼튼해지나보다.

ㅤ

Freebuff 를 사용하는 법은 간단하다.

사용중인 코딩 에이전트(예: 클로드 코드)에게

"Open source website (github.com) 링크를

참조해서 이 스킬을 설치해줘."라고 요청하면 된다.

ㅤ

설치 후에 코드를 리뷰하면.

그림에 보이는 것처럼 FREEBUFF_CDDE_REVIEW.md 파일을 만들어 주는데, 내용이 꽤 자세하다. 나는 일부러 취약점이 있는 파일을 만들어 테스트를 했는데 리뷰 수준이 만족스러웠다. 리뷰가 끝나면 에이전트에게 이 md 파일에 따라 코드를 수정하라고 요청해도 되고, Freebuff 화면에 있는 수정하기 버튼을 클릭해도 된다.

ㅤ

비개발자들이 바이브 코딩을 할 때,

"잘 돌아가는 것 같다"는 느낌에서 작업을 끝내면 나중에 로직이 무너지거나 코드가 꼬이기 쉽다. 중간중간 테스트로 검증하고, 다른 AI를 통해 리뷰하는 과정은 바이브 코딩의 필수라 생각한다. 오픈소스로 공개된 Freebuff 를 통해서 얼른 내 앱의 '감리'를 고용하시길!
