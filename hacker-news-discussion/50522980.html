2026-11-17 · comment — I'm very open-minded about entertaining drastic societal changes but I just don't think the facts support this prediction.

1. LLM performance has more or less peaked. Since Fable 5 released in June, every Claude model has been a ~1-2% improvement over the last one (if you go by benchmarks). Fable 5.2 marketing verbiage has shifted to how it's "lower cost per task" which imo marks a regime shift. I would bet money that this time next year, we're not going to have a model that's obviously and significantly better than the best ones we have today.

2. If you hold that this is about as good as LLMs are gonna get, we haven't found ourselves at a point where we can completely remove the software engineer from the seat. A software engineer is still required to create real commercial-quality software. The role hasn't been commodified either - a better software engineer still writes better software.
