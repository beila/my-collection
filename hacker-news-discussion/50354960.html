primitivesuave · 2026-11-03 · comment — Postman logs detailed information on every single API request you make through its tool, including query parameters. If you use the templating syntax `{{some_secret}}` to fill in a query parameter, it sends the actual secret content of `some_secret` to Postman's servers. If you disable outgoing network traffic to this logging endpoint, the entire app will stop working properly.

I discovered this when investigating whether Postman is HIPAA-compliant (it is not).
